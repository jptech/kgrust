# Edition 1.1 — call sites that say what they mean

*Part of the [editions](README.md). **Preview**: it may still change
before a release freezes it. Built on the `editions-pilot` branch,
2026-10-30.*

**The difference from edition 1.0, in full**, one page each:

| Feature | Adds | Name, alone |
|---|---|---|
| [Named arguments](1.1/named-arguments.md) | `sub(y: q, x: p)`: a call names its arguments by their parameters, in any order | `named-arguments` |
| [Trailing commas](1.1/trailing-commas.md) | `add(1, 2,)`: a list may end in a comma | `trailing-commas` |

Nothing else changes. Every program edition 1.0 accepts, 1.1 accepts and
means the same: each feature gives a meaning only to text the reference
rejects as a parse error, so no 1.0 program holds any of it. Each one is
rewritten inside the frontend to the program 1.0 would have written, so the
backend is given a 1.0 program.

`[package] edition = "1.1"` turns every feature on; `[language] features`
names one alone, on any edition ([opting in](README.md#opting-in)).

## Together

The features are one theme: what a call site writes says what it means,
and a list grows a line at a time.

```kanagawa
uint32 c = acc.add(
    value: a,
    shift: 2,
);
```
