# Edition 1.0 — the reference

*Part of the [editions](README.md). The default edition.*

Edition `1.0` is upstream Kanagawa at the commit `reference.lock` pins
(`98a2d8c` as of 2026-10-30): the language the reference compiler accepts,
with the meaning it gives. kgrust adds nothing to it and takes nothing away.
It is graded, not specified, here: every gate in [`../gates.md`](../gates.md)
compares kgrust's behaviour on edition-1.0 code with the reference's, and
what the reference does is written down, cited, in [`../spec/`](../spec/).
The differences kgrust keeps on purpose — none of them in the language
accepted — are [`../known-divergences.md`](../known-divergences.md).

**The difference from the edition before it:** none; it is the first.

**It follows the pin.** When `reference.lock` moves to a later upstream
commit, edition `1.0` is that commit's language. Whatever upstream adds
then is in `1.0`, and the `editions` gate's claims check says whether it
has given a meaning to syntax a later edition claims, so that the clash is
found at the pin move and settled there
([`../plans/editions.md`](../plans/editions.md) §7).

**Where it applies.** Every file whose package names no edition, every
file with no manifest above it, the standard library, the synthetic
`.cmdargs` and `.options` modules, and everything the `kanagawa` binary
compiles ([`README.md`](README.md), "Which language a file is in").
